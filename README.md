# 📊 Historical Cost of Living Index Analysis

## Overview
This project analyzes historical cost of living indices across U.S. cities using Python and Jupyter Notebook. It visualizes trends, compares regional shifts, and extracts insights from decades of economic data.

## Objectives
- 🧮 Clean and preprocess historical cost index data
- 📈 Visualize trends across time and geography
- 🧠 Identify patterns in inflation, housing, and consumer goods
- 📊 Build interactive charts for exploration

## Dataset
- Format: XLSX with city-wise cost index values from 1990 Q1 to 2024 Q3

## Key Insights
- 🏙️ San Francisco saw a 120% increase in housing index since 2000
- 🛒 Midwest cities maintained below-average cost growth
- 📉 Inflation-adjusted indices reveal real purchasing power trends

## Technologies Used
- Python, Pandas, Matplotlib, Seaborn
- Jupyter Notebook
